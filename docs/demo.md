# Попробовать Finance Tracker

[README](../README.md#попробовать-приложение) · [Помощь с Google Таблицей](sheets.md#ошибки-доступа)

Проверка готового стенда занимает около 10 минут: вы зададите бюджеты,
добавите расходы и получите отчёт. Устанавливать Go, Docker или подключаться
к серверу не требуется. Ссылку на шаблон, адрес API и данные входа владелец
передаёт отдельно. Для сценария нужен чистый демонстрационный аккаунт.

## Подключение

1. Откройте шаблон своим Google-аккаунтом и выберите **Файл → Создать копию**.
   Работайте в своей копии. Обновите страницу, чтобы появилось меню **Finance Tracker**.
2. Выберите **Finance Tracker → Подключение…**, разрешите Apps Script работу
   с таблицей, формами и внешними запросами. Введите полученный HTTPS-адрес API.
   Если Google показывает предупреждение, следуйте [инструкции подключения](sheets.md#подключение-копии).
3. Откройте **Войти или зарегистрироваться…**, сверьте адрес сервера и нажмите
   **Войти**, используя выданные данные. Регистрироваться для этой проверки не нужно.
4. На листе **Отчёт** задайте B1 `2026-10-01`, B2 `2026-10-31` и выполните
   **Загрузить отчёт за период**. У чистого аккаунта итог равен 0.
   Если в шаблоне остались примеры, очистите их только в своей копии по
   [инструкции](sheets.md#подключение-копии).

## Бюджеты

На листе **Бюджеты** заполните A2:C3:

| Категория | Лимит | Период |
| --- | ---: | --- |
| еда | 5000 | month |
| транспорт | 2500 | month |

Выберите **Finance Tracker → Сохранить бюджеты с листа «Бюджеты»**.
В колонке D обеих строк должен появиться статус **создан**.

## Расходы

Через **Finance Tracker → Добавить транзакцию…** сохраните расход:
дата `2026-10-05`, категория `еда`, сумма `1250,50`, описание `продукты`.
На листе **Транзакции** появятся строка, ID и статус **сохранена**.

Затем заполните A3:D5 следующими данными. Колонки E:G оставьте пустыми:

| Дата | Категория | Сумма | Описание |
| --- | --- | ---: | --- |
| 2026-10-05 | транспорт | 300,00 | проезд |
| 2026-10-05 | здоровье | 700,00 | аптека |
| 2026-10-05 | еда | 4000,00 | превышение лимита |

Выберите **Отправить новые строки листа «Транзакции»**. У транспорта и здоровья
появятся ID. Расход 4000 будет отклонён: вместе с уже сохранёнными 1250,50
он превышает бюджет 5000. У этой строки ID останется пустым, в статусе будет причина.

Повторите команду: сохранено 0, одна ошибка. Сохранённые расходы не дублируются.

## Отчёт и ожидаемый результат

На листе **Отчёт** оставьте период `2026-10-01` - `2026-10-31` и выполните
**Загрузить отчёт за период**. Ожидаемый итог: **2250,50**.

| Категория | Потрачено | Остаток за выбранный диапазон | Использование бюджета |
| --- | ---: | ---: | ---: |
| еда | 1250,50 | 3749,50 | 25,01% |
| транспорт | 300,00 | 2200,00 | 12% |

Расход на здоровье 700 также входит в итог; бюджет для него не задан.
При работающем Redis первый отчёт после изменений показывает MISS в D2,
немедленный повтор даёт HIT. Фиксированные даты позволяют повторить сценарий
независимо от текущего дня.

## Проверка другим пользователем

Каждому участнику нужны свои данные входа и личная копия таблицы. Для повторения
сценария с нуля получите чистый аккаунт и создайте новую копию. Удаление строк
из таблицы не удаляет сохранённые расходы на сервере. Пароли и JWT не включайте
в снимки и отчёты о проверке.

[Проверка API, исходников и локальный запуск](assessment.md#локальный-запуск-и-техническая-проверка)
описаны отдельно.
